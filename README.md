## 核心功能与模式

### 1. 赛博接线员 (自动秒接 + 扬声器播放反制音频 + 定时挂断)
- **触发机制**：后台 0.15s 毫秒级捕获企业微信来电/会议弹窗，自动点击“接听/加入”。
- **全场景覆盖**：
  - **快速会议**：自动锁定“进入会议”按钮，毫秒级入会反制；
  - **语音通话**：自动识别来电卡片，毫秒级点击绿色接听按钮；
  - **视频通话**：**触发专属防窥秒拒**！直接秒点红色拒绝按钮掐断（绝不让对方看到用户摄像头或看笑话）。
- **反制表现**：
  - 自动通过扬声器外放高保真自然人声反制音频，麦克风将声音拾音传回通话给对方；
  - **内置真实自然人声**（真实占线、老师提问、反诈警报等），并支持在界面内**输入任意台词一键在线 AI 合成**！
  - 播放指定秒数后，自动寻找“挂断/离开”按钮结束通话。

### 2. 薛定谔秒挂 (0.2秒瞬间掐断·企微玄学BUG流)
- **触发机制**：检测到来电后，点击接听等待 0.2 秒（确保服务器建立连接并记录通话时长 00:00），瞬间点击挂断。
- **效果**：对方端只会听到半声接通音便瞬间被掐断。重复数次后，对方会陷入严重的自我怀疑，以为是学校企业微信服务器出故障或其手机损坏，恶作剧热情瞬间熄灭。

### 3. 静音挂机流 (无声消耗)
- 自动秒接后保持绝对安静，让对方对着空气自言自语，消耗其手机电量与屏幕时间。

## 快速使用

1. **直接启动**：
   - **方式一（推荐）**：直接在桌面双击【**企微防骚扰反制助手**】（带专属绿色盾牌图标）；
   - **方式二**：进入工具目录双击 `start.bat`。
2. **后台挂载运行（系统托盘）**：
   - 点击【🚀 启动防骚扰守护】后，程序**默认自动隐藏至 Windows 右下角系统托盘**，桌面无残留、不占任务栏；
   - 点击界面右上角 `X` 或【🗔 挂载到后台】同样会最小化至系统托盘继续守护；
   - **双击**右下角绿色盾牌托盘图标可随时重新唤出主界面；
   - **右键**托盘图标可进行“显示主界面 / 启动停止守护 / 彻底退出”。
